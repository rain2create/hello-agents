# ReAct 数据工作流程图

## 核心循环

```
┌─────────────────────────────────────────────────────────┐
│                      开始                                │
│  Question: 用户输入的问题                                 │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  Step 1: LLM 生成 Thought + Action （prompt构造是这样的） │
│  ┌─────────────┐    ┌─────────────┐                     │
│  │  Thought    │    │   Action    │                     │
│  │  "我需要    │    │  Search[xxx]│                     │
│  │  搜索..."   │    │  或 Finish  │                     │
│  └─────────────┘    └─────────────┘                     │
└─────────────────────────────────────────────────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
    ┌─────────────────┐       ┌─────────────────┐
    │ Action = Finish │       │ Action = 工具调用 │
    │    [答案]       │       │  tool[参数]      │
    └────────┬────────┘       └────────┬────────┘
             │                         │
             ▼                         ▼
    ┌─────────────────┐       ┌─────────────────┐
    │   返回最终答案   │       │  执行工具函数    │
    │      结束       │       │  获取结果        │
    └─────────────────┘       └────────┬────────┘
                                       │
                                       ▼
                          ┌────────────────────────┐
                          │   Observation: 观察结果  │
                          │   (工具执行返回的数据)    │
                          └───────────┬────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────┐
│  更新历史记录 History                                     │
│  ──────────────────────                                  │
│  Thought: xxx                                            │
│  Action: Search[xxx]                                     │
│  Observation: {工具返回结果}  ◄── 加入历史                │
└─────────────────────────────────────────────────────────┘
                           │
                           │ 步数 < max_steps?
                           └────────► 是 → 回到 Step 1
                                       否 → 结束
```

## 数据流向

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  Question│───▶│  +      │───▶│   LLM   │───▶│ Thought │
│  History │    │ Prompt  │    │  think  │    │ Action  │
└─────────┘    └─────────┘    └─────────┘    └────┬────┘
                                                  │
                          ┌───────────────────────┘
                          │
              ┌───────────┴───────────┐
              ▼                       ▼
      ┌─────────────┐         ┌─────────────┐
      │   Finish    │         │  工具调用    │
      └──────┬──────┘         └──────┬──────┘
             │                       │
             ▼                       ▼
      ┌─────────────┐         ┌─────────────┐
      │  最终答案    │         │ Observation │
      └─────────────┘         └──────┬──────┘
                                     │
                                     └───────▶ 加入 History
```

## 关键数据结构

```python
# 历史记录 (History)
[
    "Action: Search[华为手机]",
    "Observation: 华为最新手机是 Mate 70...",
    "Action: Search[价格]",
    "Observation: 售价 5999 元起...",
    ...
]
```

## 流程特点

| 特点 | 说明 |
|------|------|
| **交错进行** | 推理(Thought) 和 行动(Action) 交替执行 |
| **观察驱动** | 每步都根据 Observation 调整下一步策略 |
| **渐进式** | 像人类一样逐步收集信息，而非一步到位 |
| **有上限** | 设置 max_steps 防止无限循环 |
