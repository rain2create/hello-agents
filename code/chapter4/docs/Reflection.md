│              │                                           │
│              ▼                                           │

│     │  type="execution"                                   │
│     └─────────────────┘                                  │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼

│             │   │  Output: 优化后的代码 Code(vN+1)     │  │
│             │   │              │                      │  │
│             │   │              ▼                      │  │

## 三种 Prompt 的作用

| Prompt | 角色 | 输入 | 输出 |
|--------|------|------|------|
| **Initial** | 程序员 | Task | 初始代码 |
| **Reflect** | 代码评审员 | Task + Code | 改进建议 |
| **Refine** | 优化程序员 | Task + Code + Feedback | 优化代码 |

## 流程特点

| 特点 | 说明 |
|------|------|
| **自我修正** | 通过反思-优化的循环不断提升质量 |
| **记忆机制** | 使用 Memory 保存所有历史记录 |
| **终止条件** | 检测到"无需改进"或达到最大迭代次数 |
| **双角色** | 执行者和评审员两个角色协作 |
