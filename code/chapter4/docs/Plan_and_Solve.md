# Plan-and-Solve 数据工作流程图

## 整体流程

```
┌─────────────────────────────────────────────────────────┐
│                      开始                                │
│  Question: 用户输入的复杂问题                             │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  Phase 1: 规划 (Planner)   第一步大模型调用  给出计划      │
│  ═══════════════════════                                 │
│                                                          │
│  Input: Question                                         │
│       + PLanner Prompt                                   │
│       ↓                                                  │
│  LLM.think()                                             │
│       ↓                                                  │
│  Output: Plan                                            │
│  ┌─────────────────────────────────────────┐             │
│  │  ["步骤1", "步骤2", "步骤3", ...]       │             │
│  │  Python列表格式                         │             │
│  └─────────────────────────────────────────┘             │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  Phase 2: 执行 (Executor)   第二步大模型调用  执行计划  结果加入history 并循环直到结束  │
│  ═══════════════════════                                 │
│                                                          │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐            │
│  │  Step 1  │───▶│  Step 2  │───▶│  Step 3  │───▶ ...  │
│  └────┬─────┘    └────┬─────┘    └────┬─────┘            │
│       │               │               │                  │
│       ▼               ▼               ▼                  │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐           │
│  │  LLM     │    │  LLM     │    │  LLM     │           │
│  │  think() │    │  think() │    │  think() │           │
│  └────┬─────┘    └────┬─────┘    └────┬─────┘           │
│       │               │               │                  │
│       ▼               ▼               ▼                  │
│  得到结果1           得到结果2         得到结果3           │
│       │               │               │                  │
│       └───────────────┴───────────────┘                  │
│                   │                                      │
│                   ▼                                      │
│         ┌──────────────────┐                             │
│         │   累积到 History  │                             │
│         └──────────────────┘                             │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    返回最终答案                          │
│              (最后一步的执行结果)                         │
└─────────────────────────────────────────────────────────┘
```

## 执行阶段详情

```
┌──────────────────────────────────────────────────────────────┐
│  Executor 单步执行流程                                         │
│  ═══════════════════                                           │
│                                                                │
│  ┌─────────────┐                                               │
│  │   当前步骤   │                                               │
│  │  "计算周二的 │                                               │
│  │   销量"     │                                               │
│  └──────┬──────┘                                               │
│         │                                                      │
│         ▼                                                      │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Prompt 构建                                             │   │
│  │  ─────────────                                           │   │
│  │  • 原始问题 (Question)                                   │   │
│  │  • 完整计划 (Plan)     ──┐                               │   │
│  │  • 历史步骤 (History) ◄──┼── 前几步的结果累积             │   │
│  │  • 当前步骤 (Current)    │                               │   │
│  └──────────────────────────┴───────────────────────────────┘   │
│                            │                                   │
│                            ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  LLM.think() → 返回当前步骤的结果                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                            │                                   │
│                            ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  更新 History                                            │   │
│  │  步骤N: xxx                                              │   │
│  │  结果: xxx  ◄── 累积到下一轮Prompt                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

## 数据流向

```
        Question
           │
           ▼
    ┌────────────┐
    │   Planner  │
    └─────┬──────┘
          │ Plan (List[str])

    ┌────────────┐
    │  Executor  │◄────────────────────┐
    └─────┬──────┘                     │
          │                            │
    ┌─────┴─────┐                      │
    ▼           ▼                      │
  Step1 ───▶ 结果1 ───▶ 累积到 History  │
    │                                  │
    ▼                                  │
  Step2 ───▶ 结果2 ───▶ 累积到 History  │
    │                                  │
    ▼                                  │
  Step3 ───▶ 结果3 ───▶ 累积到 History ─┘
    │
    ▼

    │

```

## 关键数据结构

```python
# Plan (规划器输出)
["计算周二销量", "计算周三销量", "求总和"]

# History (执行过程中累积)
"""
步骤 1: 计算周二销量
结果: 周二卖出 30 个

步骤 2: 计算周三销量
结果: 周三卖出 25 个
"""
```

## 流程特点

| 特点 | 说明 |
|------|------|
| **先规划后执行** | 一次性分解所有步骤，再依次执行 |
| **线性执行** | 按顺序执行，无循环 |
| **状态传递** | 历史结果传递给后续步骤 |
| **一次性** | 每个步骤只执行一次，无反思修正 |
