# TerminalTool 终端工具

TerminalTool 是 HelloAgents 框架的安全文件系统操作工具，允许智能体在受控环境下执行命令进行即时上下文检索。
单纯就是 让agent能够操纵你的终端的tool ！！！

## 核心操作

### 初始化

```python
from hello_agents.tools import TerminalTool

terminal = TerminalTool(
    working_dir="./codebase",  # 限制工作目录
    timeout=30                 # 命令超时时间(秒)
)
```

```python

    "command": "ls -la",
    "stdout": "...",
    "stderr": "",
```

## 使用场景示例

### 场景 1：探索式导航

```python
# 查看目录结构
terminal.run({"command": "tree -L 2"})

# 查看文件列表
terminal.run({"command": "ls -la src/"})

# 查看文件内容
terminal.run({"command": "cat README.md"})
```

### 场景 2：数据文件分析

```python
# 查看 CSV 文件前几行
terminal.run({"command": "head -20 data/sales_2024.csv"})

# 统计文件行数
terminal.run({"command": "wc -l data/sales_2024.csv"})

# 查看文件大小
terminal.run({"command": "stat data/sales_2024.csv"})
```

### 场景 3：代码库分析

```python
# 搜索 TODO 注释
terminal.run({
    "command": "grep -r 'TODO' ./src --include='*.py'"
})

# 查找函数定义
terminal.run({
    "command": "grep -r 'def ' ./src --include='*.py' | head -20"
})

# 统计代码行数
terminal.run({
    "command": "find ./src -name '*.py' -exec wc -l {} + | tail -1"
})
```

### 场景 4：日志分析

```python
# 查看日志最后几行
terminal.run({"command": "tail -50 logs/app.log"})

# 搜索错误日志
terminal.run({
    "command": "grep 'ERROR' logs/app.log | tail -20"
})

# 统计各级别日志数量
terminal.run({
    "command": "grep -o 'INFO\|WARNING\|ERROR' logs/app.log | sort | uniq -c"
})
```

## 与 ContextBuilder 集成

```python
class CodebaseAnalyzer:
    def __init__(self, codebase_path: str):
        self.terminal = TerminalTool(working_dir=codebase_path)
        self.context_builder = ContextBuilder()
    
    def analyze(self, query: str) -> str:
        # 1. 使用 TerminalTool 探索代码库
        file_list = self.terminal.run({
            "command": "find . -name '*.py' | head -20"
        })
        
        # 2. 搜索相关代码
        search_result = self.terminal.run({
            "command": f"grep -r '{query}' . --include='*.py' -A 2 -B 2"
        })
        
        # 3. 将检索结果转换为 ContextPacket
        packets = [
            ContextPacket(
                content=search_result['stdout'],
                timestamp=datetime.now(),
                token_count=len(search_result['stdout']) // 4,
                relevance_score=0.8,
                metadata={"type": "code_search", "query": query}
            )
        ]
        
        # 4. 构建上下文
        context = self.context_builder.build(
            user_query=query,
            custom_packets=packets
        )
        
        return context
```

## 命令白名单速查

| 类别 | 命令 | 用途 |
|------|------|------|
| **文件浏览** | `ls` | 列出目录内容 |
| | `cat` | 查看完整文件 |
| | `head` | 查看文件开头 |
| | `tail` | 查看文件结尾 |
| | `find` | 查找文件 |
| **文本搜索** | `grep` | 搜索文本内容 |
| **文本处理** | `wc` | 统计行数/字数 |
| | `sort` | 排序 |
| | `uniq` | 去重 |
| | `awk` | 文本处理 |
| | `sed` | 流编辑器 |
| | `cut` | 截取字段 |
| **目录操作** | `pwd` | 显示当前目录 |
| | `cd` | 切换目录 |
| | `tree` | 树形显示目录 |
| **文件信息** | `stat` | 显示文件状态 |

## 错误处理

| 错误类型 | 说明 | 示例 |
|----------|------|------|
| `CommandNotAllowed` | 命令不在白名单 | `rm`, `sudo` 等 |
| `PathTraversal` | 路径超出工作目录 | `cat ../secret.txt` |
| `CommandTimeout` | 命令执行超时 | 处理大文件时 |
| `CommandFailed` | 命令执行失败 | 文件不存在 |

## 关键要点总结

1. **安全第一**：白名单机制 + 路径检查 + 超时控制

2. **即时检索**：运行时动态加载，无需预建索引

3. **渐进式探索**：分层构建理解，按需提取信息

4. **轻量引用**：使用文件路径而非加载完整内容

5. **适用场景**：代码库分析、日志排查、数据探索
